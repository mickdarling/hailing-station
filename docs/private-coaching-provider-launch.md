# Explicit coaching provider launch — inert source (#268 / #225)

This small transport prerequisite carries an explicit advice-provider choice through the existing
CoachingChildTransport and RightyoCoachingLaunch, not a second transcript runtime or network client.
Mock remains the default. Jev requires a separate hosted-text consent, a finite 1..100 request budget,
and an absolute readable regular authored catalog of 1..8192 bytes; mock suggestions cannot be combined
with that choice. It forwards exactly the coaching provider, hosted-text consent, request-budget and
catalog flags. It never forwards ordinary hosted-ASR consent, provider credentials or new environment grants.

The agreed Rightyo source provider selects bounded authored catalog text or abstains; it does not generate
commands or grant capture/playback authority. Rightyo validates catalog semantics before provider work.
The catalog is an explicit trusted local operator input, not an atomic snapshot against hostile same-account
file replacement. Original capture qualification, measured activity, advice expiry, private playback and
owned-child retirement remain unchanged. No ordinary child opts into this capability implicitly.

Tests use pure argv validation and an authored shell child recording its actual arguments. They do not run
Jev, TLS, credentials, models, native audio factories, devices or installed speech services. The sealed
qualified b244 synthetic launcher remains mock-only and rejects hosted/native execution. Actual command
configuration forwarding, final integrated reviews, refreshed mock composition and a later scoped human
hosted-text/service-budget decision remain separate requirements. This unmerged source does not activate
any provider, install or deploy anything, or establish physical privacy or advice quality.

The first full parallel verifier failed the new argv fixture's active-owner assertion, although all argv
assertions passed. That fixture suppressed the coordinator's renewal scheduler while retaining the real
two-second audio lease; scheduling contention allowed the lease to expire. A controlled no-renewal case
now demonstrates the same real expiry, capture retirement and zero playback beyond the original deadline.
The argv case uses the actual renewal scheduler, preserving its active-owner and zero-playback assertions.
Production TTL, cadence, scheduling and retirement guards are unchanged. The failed run and captures remain
preserved; only a new complete exact-head verifier and independent reviews can qualify this integrated slice.

A later independent run exposed a verification defect in that negative: expiry plus 100ms does not guarantee
delivery of the asynchronous expiry callback. Controlled delayed actor schedules reproduced stale stored
status, while actual late heartbeat, buffer and ticket effects still refused the original deadline. The
corrected regression deliberately withholds both timer deliveries and tests those three effect boundaries,
then waits boundedly for owned retirement. It requires exactly one original qualification, zero forwarded
expired PCM, zero playback, and no revival from duplicate old callbacks. No production deadline or assertion
about expired effects is weakened; both failed evidence and the independent probes remain preserved.
